# 📊 Data Visualization Project

A collection of data visualization techniques implemented in Python to transform raw datasets into meaningful insights. This project demonstrates the use of exploratory data analysis (EDA), statistical visualization, and interactive graphics to communicate patterns, trends, and relationships within data.

---

## 📌 Project Overview

The objective of this project is to explore datasets using visual analytics and create clear, informative visualizations that support data-driven decision making.

The project covers the complete visualization workflow:

- Data loading
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Statistical summaries
- Data visualization
- Insight generation

---

## 🚀 Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Distribution analysis
- Correlation analysis
- Categorical data visualization
- Time series visualization (if applicable)
- Statistical summaries
- Publication-quality charts

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/pereramanuth/Data-Visualization-Project.git
cd Data-Visualization-Project
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook and run all cells.
